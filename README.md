## Setup

1. Copy `.env.example` to `.env` and fill in your values (especially DB_PASSWORD and SESS_SECRET).
2. Make sure MySQL is running and database `bank_buku` exists (or let Sequelize create it).
3. `npm install`
4. `node index.js`

The app will now validate DB connection on startup.
